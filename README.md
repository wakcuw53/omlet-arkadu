# ArcadeLink v0.4

Независимый Android-проект игрового сообщества, вдохновлённый старой атмосферой Omlet Arcade. Неофициальный проект, не связан с Omlet или Mojang.

## Готово в v0.4
- Новый логотип и значок приложения в оранжево-тёмном стиле, плавные градиенты, переработанные кнопки.
- Переработанная главная без выдуманных игроков, демо-комнат, «Играй с друзьями» и фиктивных блоков стримов.
- Одна нижняя навигация: Главная, Комнаты, центральное +, Клубы, Чат. Убрана вторая строка HOME / GAMES / CLUBS / FEED.
- Экран приветствия, регистрация, вход, гостевой режим, профиль и выход. Пароли проверяются **локально**, онлайн-синхронизации нет.
- Реальные пользовательские записи комнат с адресом и портом Minecraft Bedrock-сервера, локальное сохранение, приглашение.
- Пустые экраны показывают понятное сообщение вместо поддельного контента.

## Ограничения
Сам клиент **не запускает Minecraft-сервер**. Для общих комнат и чата нужен отдельно работающий ArcadeLink API. Прямое соединение с миром друга через интернет, стримы, запись экрана и голосовые звонки пока не реализованы.

## Скачать APK
Откройте [успешную сборку 0.4](https://github.com/wakcuw53/omlet-arkadu/actions/runs/39906651699), раздел Artifacts → `ArcadeLink-v0.4-debug-APK`. После распаковки установите `app-debug.apk` на Android 8+.

Это тестовая сборка; на настоящем устройстве интерфейс ещё не проверен.
