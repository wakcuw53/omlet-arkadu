# ArcadeLink 0.3 Android

Независимый проект в стиле классического игрового сообщества, вдохновлённый интерфейсом Omlet Arcade, но не связанный с Omlet.

## В новой версии
- Настоящие экраны первого запуска, регистрации, входа и гостевого режима.
- Локальные аккаунты: пароль хранится как PBKDF2-HMAC-SHA256 с солью, вход и выход работают на одном телефоне; перенос аккаунтов и сброс пароля пока отсутствуют.
- Компактная лента с игровыми карточками, демо-профилями, вкладками HOME/GAMES/CLUBS/FEED, кнопкой действий и профилем.
- Оригинальный значок приложения и иллюстрация запуска.
- Комнаты Minecraft Bedrock с вводом IP/порта, локальное сохранение, чат при подключённом ArcadeLink API.

## Ограничения
Нет общего сервиса учётных записей и связи между телефонами. Демо-игроки, клубы и комнаты не являются онлайн-контентом. Прямое подключение к миру друга, голосовой чат и стримы ещё не реализованы. Не выдавать эту сборку за официальный Omlet Arcade.
