# ArcadeLink v0.2 — Android

Независимый игровой Android-клиент в стиле классического Omlet Arcade. Это не официальный Omlet Arcade и не восстановление его серверов.

## Что работает

- Тёмный игровой интерфейс с оранжевыми акцентами, главный экран, поиск миров, клубы, чаты, профиль и центральное меню действий.
- Новый оригинальный значок и фоновая иллюстрация воксельного мира.
- Анимации переходов и нажатий.
- Создание локальных комнат и клубов, сохранение на устройстве.
- Подключение к Minecraft Bedrock-серверам и доступ к чату комнат, если настроен отдельно работающий ArcadeLink API.

## Что пока не работает

- Подключение к открытому миру телефона друга через интернет; голосовой чат и streaming; запись экрана.
- Без сервера карточки примеров — демонстрационные, не активные мультиплеерные миры.

## Скачать APK

Откройте [последнюю успешную сборку GitHub Actions](https://github.com/wakcuw53/omlet-arkadu/actions/workflows/build.yml), внизу страницы сборки в разделе **Artifacts** выберите **ArcadeLink-v0.2-debug-APK**, распакуйте архив, установите `app-debug.apk` на Android 8+.

Приложение собирается Java/Gradle 8.9 и Android SDK 35. Для запуска серверной части см. исходный проект ArcadeLink.
