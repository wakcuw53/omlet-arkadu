# ArcadeLink для Android

Независимое приложение по мотивам старого Omlet Arcade: комнаты Minecraft Bedrock, чат и приглашение друзей.

Тестовый APK собирается в GitHub Actions. Входные Android-исходники хранятся в `android-source.tar.gz.b64`. Скачайте их и распакуйте с помощью команды `base64 -d android-source.tar.gz.b64 | tar xz`.

Для работы чатов требуется отдельно запущенный сервер ArcadeLink. Сама программа не пробрасывает мир Minecraft через интернет. Проект не связан с Omlet Arcade, Mojang или Microsoft.
